# Triage Labels

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required. |
| `needs-info` | `needs-info` | Reporter input is required. |
| `ready-for-agent` | `ready-for-agent` | Specification and acceptance criteria are sufficient for agent implementation. |
| `ready-for-human` | `ready-for-human` | Human judgment or access is required. |
| `wontfix` | `wontfix` | The request will not be implemented. |

Matt Pocock workflow skills use the role in the left column and apply the corresponding repository label.
