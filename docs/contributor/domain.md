# Domain Documentation

LiteORM is a single-context repository.

Before exploring or changing a subsystem:

1. read the root `CONTEXT.md` glossary;
2. read ADRs under `docs/adr/` that touch the subsystem;
3. use glossary terms in issues, code, tests, diagnostics, and documentation;
4. surface a contradiction with an ADR instead of silently overriding it.

When a durable term or architectural decision is resolved, update `CONTEXT.md` or add an ADR. Implementation status remains in GitHub Issues.
