# Select JDBC type mappings per Mapper package

LiteORM selects one explicit `JdbcTypeMappings` collection from each Mapper package's `package-info.java`, validates its `TypeHandler` declarations during compilation, and generates an immutable Mapper-local `JdbcTypeRouter`. Parameter routes use the declared Java type plus optional placeholder `jdbcType`; result routes use the generated Java target type plus JDBC `ResultSetMetaData`, including the vendor type name when a mapping declares one. Resolution occurs once per result set and is reused for every row. PostgreSQL and MySQL mappings remain separate artifacts, while users and third parties may publish additional mapping artifacts. This combines generated object construction with runtime JDBC type selection without schema discovery, reflection, classpath scanning, `ServiceLoader`, or a mutable global registry.
