# @kervix/skill

Install the Kervix Agent Skill without downloading the full source repository.

```bash
npx @kervix/skill install codex
npx @kervix/skill install claude
npx @kervix/skill install cursor
```

Pin a release with `--version v1.0.0`. The package is an installer only; the
canonical skill content is published from `skills/kervix` in the Kervix repository.
