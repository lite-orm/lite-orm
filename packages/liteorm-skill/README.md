# @lite-orm/skill

Install the LiteORM Agent Skill without downloading the full source repository.

```bash
npx @lite-orm/skill install codex
npx @lite-orm/skill install claude
npx @lite-orm/skill install cursor
```

Pin a release with `--version v1.0.0`. The package is an installer only; the
canonical skill content is published from `skills/liteorm` in the LiteORM repository.
