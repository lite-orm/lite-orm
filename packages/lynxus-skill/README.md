# @lynxus/skill

Install the Lynxus Agent Skill without downloading the full source repository.

```bash
npx @lynxus/skill install codex
npx @lynxus/skill install claude
npx @lynxus/skill install cursor
```

Pin a release with `--version v1.0.0`. The package is an installer only; the
canonical skill content is published from `skills/lynxus` in the Lynxus repository.
