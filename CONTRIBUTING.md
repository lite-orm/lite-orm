# Contributing to Lynxus

Thank you for helping build a new generation of explicit, compile-time Java ORM tooling. The contributor workflow and engineering boundaries are documented in [docs/contribute.md](docs/contribute.md).

Before opening a Pull Request:

- read `AGENTS.md` and the relevant contract documentation;
- keep the branch focused and based on `main`;
- add or update tests and documentation with the behavior change;
- run the narrowest relevant checks and include their commands in the PR;
- use the repository Pull Request template.

AI agents may contribute. Install and invoke the unified `$lynxus` skill; it scans first, creates bounded TODOs, and pauses for user decisions when semantics or authorization are unclear.
